dex+- (also known as dexplusminus or dexpm) is a fork of Dex++ by Chillz (AZYsGithub) https://github.com/AZYsGithub/DexPlusPlus.

dex+- is not intended for exploits or gaining an advantage over other players.

dex+- is a hobby project, so it may not get updates often or ever.

features (useless ones):

a favorite option to favorite a item to find it easily (available until you leave the game)

model/part to tool, select a model then click a button and it turns into a client side tool (the tool is a COPY of the model/part)
